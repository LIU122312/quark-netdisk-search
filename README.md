# 夸克资源检索 · Quark Netdisk Search

一个跑在自己电脑上的**夸克网盘资源检索台**：聚合 Telegram 网盘分享频道 + 几十个影视站插件，
结果**只保留夸克链接**，并自带本地精选库、链接判活、影视榜单。

> 纯本地运行 · 不接触你的网盘账号密码 · 只监听 127.0.0.1

![动漫榜单](docs/v1-anime-bgm.png)
![电影榜单](docs/v3-movie-db.png)

## 功能

- **搜索**：本地精选库（离线，秒出）+ PanSou 在线聚合（TG 频道 + 插件并发抓取）
- **筛选**：只要合集/全集、排除预告花絮电子书、只要 4K、结果内二次筛选
- **判活**：两步校验分享链接，标记失效 / 违规 / 封禁 / 已取消
- **转存**：一键调起夸克客户端打开链接，保存到自己的网盘
- **榜单**：动漫 / 电影 / 剧集三大类
  - 每类可自由切换来源：**Bangumi**、**豆瓣**、**固定榜单**（Top250 / 一周口碑 / 正在热映 …）
  - 产地 + 题材**多选**（多选为「同时满足」），300ms 防抖
  - 点封面直接搜该片资源，「加载更多」翻页

## 快速开始（下载便携包）

1. 到 [Releases](../../releases) 下载 `夸克资源检索-*-win64.zip`（约 55 MB）
2. 解压到任意目录
3. 双击 `夸克资源检索.cmd`

不需要装 Node.js，不需要管理员权限，不写注册表。

**建议开着代理**（Clash Verge 等，默认读 `127.0.0.1:7897`）：
有代理时 Bangumi 榜单和 Telegram 频道全部可用；没代理时本地精选库和部分插件源仍能用。

## 从源码运行

```bash
node app/ui/server.js     # 需要 Node 18+，只用内置模块，无需 npm install
# 打开 http://127.0.0.1:8899
```

还需要一个 PanSou 搜索 API 在 `127.0.0.1:8888`（见下）。

## 数据源

| 来源 | 接口 | 说明 |
| --- | --- | --- |
| PanSou | `127.0.0.1:8888` | 搜索引擎本体，TG 频道 + 插件聚合（第三方，见 THIRD-PARTY.md）|
| Bangumi | `api.bgm.tv/v0/search/subjects` | 全站排名，tag 多选为 AND，单请求上限 20 条 |
| 豆瓣 | `m.douban.com/rexxar/api/v2/*` | 固定榜单 + `/recommend?tags=` 组合筛选（单页上限 100，单标签约 500）|
| 豆瓣 | `movie.douban.com/j/chart/top_list` | 动画高分库（区间 100:90 / 90:80 / 80:70）|

Bangumi 需要代理（本机 7897），豆瓣直连即可。

## 目录结构

```
app/
  ui/server.js         Web 服务：静态页 + 搜索代理 + 判活 + 转存 + 榜单路由
  ui/rank.js           榜单数据层：多源抓取 / 组合筛选 / 分级缓存
  ui/index.html        单文件前端
  lib/index.json       本地精选库（离线索引，可重建）
  lib/build-index.js   精选库构建脚本
package/
  launcher/            便携包里的启动器与配置模板
  build.js             一键组装便携包（含 Node 运行时）并打包 zip
docs/                  截图
```

## 榜单缓存

`lib/rank-cache.json` 是运行时缓存（Bangumi 池 12 小时、豆瓣池 6–12 小时、固定榜单 3–24 小时）。
删掉即强制重建；服务启动时会后台预热电影/剧集/动漫三个分类。
